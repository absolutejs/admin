## 0.3.0 — 2026-10-26

### Changed

- **The `developer` role now includes `site.secrets.manage` and `site.data.manage`. Deploy access already reaches both, so withholding them only sent routine changes through an administrator; team management, security response and deletion still need a higher role** (`capabilitiesForRole`, `roleHasCapability`, `authorizeSiteAdmin`)
- **`manifest` is typed by the current `@absolutejs/manifest`: `contract` is `1` or `2`, `tools` follows the contract, and `settings` is a TypeBox object. The values are unchanged** (`manifest`)
